# Mintools

一个用于整理各种开发所需小工具的项目。

## 功能

- **JSON 编辑器**：提供 JSON 数据的输入、格式化和展示功能。
- 更多小工具正在开发中...

## 快速开始

1. 克隆项目：
   ```bash
   git clone https://github.com/your-repo/mintools.git
   ```
2. 安装依赖：
   ```bash
   cd mintools && npm install
   ```
3. 启动开发服务器：
   ```bash
   npm run serve
   ```

## 项目结构

- `src/App.vue`：主组件，包含 JSON 编辑器功能。
- `src/main.js`：Vue 应用的入口文件。
- `package.json`：项目配置和依赖管理。
